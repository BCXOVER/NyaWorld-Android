# NyaWorld Android

Экспериментальный Android-лаунчер для Minecraft Java **1.21.1** / **NeoForge 21.1.250** и сервера NyaWorld.

> **Статус: экспериментальная Android-сборка.** На базе XDAetherium добавлен экран синхронизации NyaWorld. Он проверяет PC-манифест и по отдельному подтверждению скачивает файлы в `profiles/NyaWorld`. **Minecraft/NeoForge автоматически не устанавливаются, а моды Android не тестировались**. Не распространять как готовый клиент сервера.

## Цель проекта

- один установочный APK для POCO X6 Pro (12 ГБ RAM) и Redmi Pad SE (6 ГБ RAM);
- после установки: загрузка нужной версии Java/Minecraft/NeoForge/модов и конфигураций;
- заранее добавленный сервер `nyanimeon.millida.host`;
- сенсорное управление в стиле Minecraft Bedrock и поддержка клавиатуры/мыши;
- раздельные графические пресеты телефона и планшета.

## Что делает текущая сборка

Workflow [Build Android test APK](.github/workflows/build-android.yml) клонирует [XDAetherium](https://github.com/Promastergame/XDAetherium), добавляет [`NyaWorldSyncActivity`](android/NyaWorldSyncActivity.java) и собирает тестовый APK. Он проверяет PC manifest.json и может по отдельному подтверждению загрузить изменённые файлы в профиль `profiles/NyaWorld`, но пока не настраивает автоматический запуск Minecraft/NeoForge или подключение к серверу. Состав модпака на Android не протестирован.

1. Откройте **Actions** → **Build Android test APK**.
2. Выберите **Run workflow**, если автоматический запуск ещё не состоялся.
3. Дождитесь успешного статуса; внизу страницы запуска смотрите **Artifacts → nyaworld-engine-test-apk**.
4. Архив артефакта содержит APK для **тестирования движка**, не готовый NyaWorld.

Если сборка не удалась, приложите лог её последнего ошибочного шага к задаче в репозитории.

## Данные игровой сборки

По переданному инвентарю в NyaWorld 428 JAR-модов (~868 МБ ZIP), отдельно получены `config/`, `kubejs/`, `defaultconfigs/`. **Они умышленно не загружены в публичный GitHub**: здесь нет подтверждённых прав на перераспространение всех модов, текстур и скриптов. В конечном клиенте игровые данные должны загружаться из разрешённого пользователем источника. Не храните пароли Ely.by, ключи подписания и личные токены в публичном репозитории.

Собственный Windows EXE нельзя механически конвертировать в Android APK. Требуется Android-приложение на основе Minecraft Java launcher, установка NeoForge и проверка модов. На Redmi Pad SE полная сборка может оказаться непригодной из-за ограничений GPU/RAM.
